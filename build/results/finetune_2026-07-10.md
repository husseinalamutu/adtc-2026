# Nigeria-accuracy retrain (v2) — 2026-07-10

Retrain to fix v1's Nigeria numeric hallucinations (VAT 5.5%→7.5%, small-co thresholds, Dev
Levy rate, professional-services exclusion). Same QLoRA recipe as v1 (see finetune_2026-07-09.md);
what changed is the data.

## Data changes vs v1
- Nigeria fact-drill layer regenerated: **149 → 500** examples (number-first repetition style,
  includes the professional-services exclusion cases). Groq `llama-3.1-8b-instant`.
- Rebuilt dataset: 3,748 raw → **3,325 train / 423 holdout** (94/12 scenario families,
  zero overlap). Train mix: reconciliation 1,386, invoice 635, quote 603, nigeria_tax 476,
  advisory 225. All 118 data tests pass.
- MLX prep with `--oversample-factor 2`: nigeria_tax 447 base in train → +447 copies →
  **3,606 rows, ~25% Nigeria exposure** (vs ~5% in v1).

## Validation-loss trajectory (val_batches=15, ±0.03 noise)
| global iter | val loss |
|---|---|
| 0 (baseline) | 2.230 |
| 100 | 1.409 |
| 200 | **0.375 (best)** |
| 300 | 0.396 |
| 400 | 0.453 |

Stopped at global 400: no improvement past 200, upward drift setting in — same post-plateau
shape v1 showed after its best. Slower early convergence than v1 (1.409 vs 0.490 at iter 100)
is the short drill rows carrying fewer tokens/iter, not a problem.

## Checkpoint selection — operational note
The **global-400** weights (`adapters_best/global0400_val0453.safetensors`, = the fused
candidate) shipped to the GGUF build, NOT the val-best global-200: `resume_training.sh`
deletes numbered checkpoints on resume, and the run was resumed once (session teardown at
~global 340), destroying the 200/300 files. Acceptable trade: the extra 200 iters are mostly
extra drill repetition (helps fact recall — the thing this retrain is for), and 0.453 vs
0.375 is modest. If the fact check or smoke quality disappoints, retrain fresh and stop at
200. TODO for any future run: copy each `NNNN_adapters.safetensors` into `adapters_best/`
*before* resuming.
